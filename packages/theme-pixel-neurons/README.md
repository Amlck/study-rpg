# @study-rpg/theme-pixel-neurons

Pixel-art theme pack scaffold for the neurons-themed (Long-term potentiation / Hebbian) reskin of study-rpg. **Scaffold stage only** — `THEME_PIXEL_NEURONS` provides a minimal placeholder satisfying `theme-pack-contract` (5 required sprite keys mapped to 1×1 transparent PNG; empty cssVars / fonts / itemCatalog).

Real palette, sprites, cosmetic catalog, item catalog, and skill-tree branches are deferred to follow-up OpenSpec changes [`wire-neurons-content-and-theme`](../../openspec/changes/) and [`generate-neurons-sprites`](../../openspec/changes/).

See [DESIGN.md](DESIGN.md) for visual direction preview and [`openspec/specs/neurons-mode/spec.md`](../../openspec/specs/) for the umbrella capability contract.
