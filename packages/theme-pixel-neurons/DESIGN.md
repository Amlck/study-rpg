## Visual direction (preview — locked by `neurons-mode` umbrella spec)

- **Style**: GBA-era pixel art; cute / collectable; soma sprites with chibi facial features (eyes, optional crown / glow for mastered variants).
- **Core visual**: Linnean phylogenetic taxonomy tree. Root → 4 NT main branches (DA / 5-HT / GABA / Glu) → neuron family clusters → individual variants (P1–P5 rarity).
- **Overlay**: Dynamic synapses connecting clusters across NT branches (Hebbian wiring layer; potentiated → glowing, dormant → dotted, decaying → fading).
