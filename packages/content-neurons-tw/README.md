# @study-rpg/content-neurons-tw

Content pack scaffold for the neurons-themed (Long-term potentiation / Hebbian) reskin of study-rpg's Stage-1 medical board exam app. **Scaffold stage only** — the placeholder `getContentPack()` returns empty subjects + empty questions.

Question corpus reuse (from the existing `@study-rpg/content-medexam-tw` source), subject rename to neuron families along a Linnean phylogenetic taxonomy (4 NT branches × N families), and `statSchema` override (DA / 5-HT / GABA / Glu) are deferred to the follow-up OpenSpec change [`wire-neurons-content-and-theme`](../../openspec/changes/).

Umbrella capability spec: [`openspec/specs/neurons-mode/spec.md`](../../openspec/specs/) (lands after `add-neurons-mode-scaffold` archives).
