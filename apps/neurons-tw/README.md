# @study-rpg/neurons-tw

Neurons-themed (Long-term potentiation / Hebbian) reskin of the Stage-1 medical board exam study-rpg app. **Scaffold stage only** — placeholder shell at `/` displaying the app title and a pointer to the umbrella capability spec.

Game logic, content (neuron families on a Linnean phylogenetic taxonomy across 4 neurotransmitter branches), sprite atlases, variant gacha, family mastery, leaderboard, achievements, and cloud sync are delivered by follow-up OpenSpec changes — see [`openspec/changes/`](../../openspec/changes/) and [`openspec/specs/neurons-mode/spec.md`](../../openspec/specs/) (lands after `add-neurons-mode-scaffold` archives).
